# Datos

Descargue el dataset **YouTube Statistics** desde Kaggle y coloque aquí los dos archivos:

- `videos-stats.csv` (1.881 videos)
- `comments.csv` (18.409 comentarios con etiqueta de sentimiento 0/1/2)

Fuente: https://www.kaggle.com/datasets/advaypatil/youtube-statistics

Los CSV no se versionan en el repositorio (ver `.gitignore`).
